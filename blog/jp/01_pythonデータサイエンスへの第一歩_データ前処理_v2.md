## 📊 第6章：トレンド分析

### 📈 年平均の計算

```python
# 年平均のCO2濃度を計算
yearly = df.groupby('Yr')['CO2'].mean()

# 線形回帰で傾向を分析
X = yearly.index.values
Y = yearly.values
a, b = np.polyfit(X, Y, 1)

# 結果の表示
print(f"毎年のCO2増加量: {a:.2f} ppm/年")
```

クルミ：「えっと...これは何してるの？」

ジャービス：「簡単に言うと、毎年どのくらいCO2が増えているか計算してるんだ。」

### 🔮 未来予測

```python
# 未来予測のグラフ
future_years = np.arange(1958, 2050)
plt.figure(figsize=(12, 6))
plt.plot(X, Y, 'o', label='実測値')
plt.plot(future_years, a * future_years + b, 
         'r--', label='予測')
plt.title('CO2濃度の未来予測...')
plt.xlabel('年')
plt.ylabel('CO2濃度(PPM)')
plt.legend()
plt.grid(True)
plt.show()
```
